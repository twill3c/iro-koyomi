# 色票出典の候補調査(F-03 着手前・人間承認待ち)

調査日 2026-08-22。**結論を先に言うと、伝統色の HEX に一次出典は事実上存在しない。**
流通している数値はいずれも少数の書籍(PIE BOOKS『日本の伝統色』2007 / 長崎盛輝 / 日比野・福田)の
派生か、出所不明の近似値である。この事実自体が本アプリの主張(「色名は言葉であって数値ではない」)の
証拠になるため、隠さず主題として扱う。

## 推奨: A + B の 2 系統 + C は参照リンク

- A と B は**独立に編集された** CC BY-SA の表であり、同じ色名で値が食い違う。これがそのまま ΔE の題材になる
- どちらも数値の出所を示していない。UI では「出典 A / 出典 B」の欄に **「HEX の典拠: 記載なし」** を明示する。
  B の「近似色であり一例」は原文引用として掲げる価値がある
- C は「唯一の公的基準が存在するが、その値は本アプリに載っていない」ことを説明する参照リンクとして置く。
  これは欠落ではなく、規格票の扱いに関する意図的な設計判断である
- CC BY-SA の継承条件により、**両出典から作った色票データは CC BY-SA 4.0 で再配布する**(コードは MIT のまま)

## 未決(人間の承認が必要)

1. A + B の 2 系統でよいか(3 系統目を足すなら、出所を辿れる根拠が必要)
2. 色票データを CC BY-SA 4.0 で再配布する方針でよいか(フリート他プロジェクトは MIT のみ)
